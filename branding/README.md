# cuedo branding

- `cuedo.svg`: main plaque logo (single colour, `currentColor`).
- `cuedo-wordmark.svg`: lettering only, for shallow headers.
- `favicon.svg`: square browser-tab icon made from the plaque magnifier, with fixed colours on a dark tile so it works on light and dark tabs.

The logos use `currentColor`, so they are inlined in HTML where they should follow the page text colour. In an `<img>` tag they would render black.
